To run the project, enter the following command in the terminal: clone --single-branch --branch pokedex-project-joanna-pagowska https://github.com/Asia969-pl/pokedex.git. 
Then go to the pokedex folder, enter the following command in the terminal  npm i 
Go to the next pokedex folder and enter npm i and then npm run dev. 
For the application to work correctly, you need to start the json server. To do this, open the terminal again, go to the pokedex folder and enter the command $ json-server --watch database.json. The application should work correctly.
